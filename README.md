# Dóblate

Juego educativo en español que enseña el **crecimiento exponencial**. Empiezas en `1` y cada nivel completado duplica el número: `1 → 2 → 4 → 8 → …`

## Desarrollo

```bash
npm install
npm run dev
```

## Pruebas

```bash
npm test
```

## Producción

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript + Vite
- Estado en el cliente con `localStorage` versionado
- `BigInt` para potencias de dos exactas
